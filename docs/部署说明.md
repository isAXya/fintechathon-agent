# 部署说明

## 一、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 运行时 | Node.js 18 或以上 | 只用标准库 http/fs/path，无第三方包 |
| 浏览器 | Chrome 100+ / Edge 100+ / Safari 16+ | 需支持 ES Module 与 `crypto.subtle` |
| 磁盘 | 约 1 MB | 项目本身很小，不含依赖 |
| 网络 | 演示时不需外网 | 大模型兜底默认关闭 |

Node 18 是下限，因为审计链用到了 Web Crypto 的 `subtle.digest`。低版本会走内置的哈希回退实现，功能不受影响，但摘要不是真正的 SHA-256。

## 二、本地运行

```bash
cd fintechathon-agent
node server.js
# 浏览器打开 http://localhost:5173
```

换端口：

```bash
PORT=8080 node server.js        # macOS / Linux
set PORT=8080 && node server.js  # Windows CMD
$env:PORT=8080; node server.js   # PowerShell
```

必须通过 HTTP 打开，不能直接双击 `index.html`。原因是 ES Module 在 `file://` 协议下会被浏览器的同源策略拦截，页面会白屏。

## 三、内网部署

作品是纯静态站点加一个静态文件服务，任选一种方式。

**方式一：沿用自带的 server.js**

把整个目录拷到服务器，用进程守护工具拉起来即可：

```bash
nohup node server.js > app.log 2>&1 &
```

**方式二：交给 Nginx**

把项目根目录作为站点根目录，指向 `index.html`：

```nginx
server {
    listen 80;
    server_name bank-agent.internal;
    root /opt/fintechathon-agent;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

**方式三：打包给评审离线看**

项目没有任何依赖，直接压缩整个目录（排除 `.git`、`node_modules`）发过去，对方解压后执行 `node server.js` 即可。这是比赛提交采用的方式。

## 四、接入真实银行核心

当前 `src/bank.js` 是内存模拟。替换成真实接口时，只需要改这一个文件里的方法实现，上层五个模块（nlu / planner / risk / executor / app）不用动。

约定三条：

1. 每个方法返回 `{ ok: boolean, data?: object, error?: string }`，失败不抛异常。
2. 金额一律用元为单位的两小数，不要传分。
3. 写操作返回凭证号，供回滚使用。

例如转账方法，把内存扣减换成 HTTP 调用：

```js
async transfer({ payee, amount, note }) {
  const res = await fetch('/api/transfer', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ payee, amount, note })
  });
  const data = await res.json();
  if (!res.ok) return { ok: false, error: data.message };
  return { ok: true, ...data };
}
```

改造后要把 `executor.js` 里的 handler 改成 `await`，其余不用动。

## 五、常见问题

**页面白屏**

九成是用了 `file://` 直接打开。用 `node server.js` 起本地服务。

**审计链校验总是不通过**

检查是否在浏览器里手动改过 `audit.records`，或者两次运行混用了缓存。刷新页面会重建内存态。

**动态码输对了还是失败**

固定码是 `246810`，六位，不要带空格。连续错三次会触发熔断，刷新页面可恢复。

**端口被占用**

`PORT=5174 node server.js` 换一个端口，或者先 `netstat -ano | findstr 5173` 找到占用的进程。

## 六、目录权限

部署时只需要读权限。作品不写文件、不连数据库，审计数据在内存里，刷新即复位。这一点在安全自评报告的风险清单里标为 R4，生产环境需要接持久化存储。
